# 本地演示登录设计

## 范围

为 `apps/admin` 实现 Vben 风格的本地演示认证，不接入后端、注册、找回密码或动态权限。唯一账号为 `vben / 123456`。

## 会话

认证模块暴露读取、登录和退出三个函数。成功登录生成固定格式的演示 `accessToken` 与用户信息：勾选“记住我”存入 `localStorage`，否则存入 `sessionStorage`。读取时只接受结构完整的会话；退出同时清除两处存储，防止切换选项后残留会话。

## 路由与交互

`/auth/login` 显示账号、密码、记住我和提交状态。凭证错误时就地提示；提交成功后优先跳回 URL 中同源的 `redirect`，否则进入 `/dashboard`。已登录用户访问登录页同样跳至工作台。

管理端路由由单一认证守卫保护：未登录时跳转登录页，并携带当前 pathname 与 search 作为 `redirect`。现有退出操作改为清空认证会话后转登录页。锁屏保持独立，不替代登录状态。

## 验证

覆盖认证模块的登录、存储、退出与无效会话；覆盖路由回跳与受保护页面重定向。再执行 `pnpm --filter admin build`。
